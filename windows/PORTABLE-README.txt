Vizruna - Windows x64

Extract this ZIP into a folder and run Vizruna.exe.
The .NET runtime is included. Administrator access is not required.
This portable build is not code-signed.

1. Open an image, paste an image, or choose Capture screen area and drag
   around the Revit viewport. Press Esc to cancel a screen selection.
2. Choose Prepare image. Drag the corner handles to crop. For a photograph
   taken at an angle, enable Correct perspective and enter the viewport's
   true width:height ratio, such as 16:9.
3. Choose Visualize. Enter your own OpenAI API key in the masked dialog.
   Remember on this PC encrypts it for your Windows account. Clear key
   removes the remembered copy. Otherwise the key lasts for this session.
4. Compare Original, Result and Overlay. Scroll to zoom and drag to pan.
   Both images share the same zoom and pan. Reset view restores the fit.
5. Save PNG writes the exact returned PNG at its native resolution.

Image generation uses your paid OpenAI account and can take several minutes.
Cancellation closes the local request; a submitted request may still finish
and be billed. Interrupted requests are not automatically resubmitted.

AI image editing cannot guarantee exact geometry. Inspect the original and
overlay, especially openings, rooflines, proportions and the viewpoint.

Keep your key private. Enter it only inside the app, never in GitHub issues
or chat. The app connects directly to OpenAI and has no backend or analytics.
Working images are private to the current Windows user and session. Export
results you want to keep before closing the app.
